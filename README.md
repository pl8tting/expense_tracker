# Expense Tracker

A command-line expense tracker built with Python. The application allows users to add and view expenses, calculate totals by category, and store expense data locally using JSON 

## Features
- Add, remove, and view expenses
- Calculate totals by category
- Store data locally using JSON so it persists between program sessions

## How It Works

Expenses are stored in a local JSON file.

When the program starts, it loads previously saved expenses. Users can add, remove, and view expenses, while the application can calculate totals based on expense categories.

Changes are saved so the expense data remains available between program sessions.

## Usage

Run the application with:

```bash
python budget.py
```
